# MinUI Amber v0.3 - YMC A10 Mini

**New device: YMC A10 Mini** (v1, v2 and V4), on its stock ArkOS4Clone firmware. One download covers all three; the V4's 720x540 screen is picked up automatically. The V4 has not been tested on hardware yet.

Install from EmulationStation's Ports menu, like the other devices. See INSTALL.txt.

**60 Hz screen.** The A10 Mini's screen runs at 57.7 Hz from the factory (61.7 Hz on the V4), so games ran slightly slow or fast. Enabling MinUI Amber sets it to 60 Hz by changing only the screen's clock speed. Any remaining mismatch is matched in the audio, so there is no crackle.

**Also in this build**
- Sega Genesis (MD) and WonderSwan Colour (WSC) added.
- Tools > Display Fix: colour correction for A10 Mini screens that look dark straight on.
- A tap of POWER shuts the device down.
- PortMaster ports run at full CPU speed instead of menu speed.

The RG351V, RPP and V90S stay on v0.2.
